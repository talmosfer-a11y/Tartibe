# خطة التنفيذ

## المرحلة 0 — التأسيس
- مراجعة التصميم القديم ومقارنته بالهيكل الجديد.
- تشغيل المشروع محليًا والتحقق من البناء.
- ربط GitHub وVercel وSupabase.

## المرحلة 1 — الحساب والرحلات
- تسجيل الدخول بالبريد والتحقق من الجلسة.
- إنشاء رحلة وتعديلها وحذفها.
- حفظ الرحلات والمدن والأيام في Supabase.
- اختبار سياسات RLS بحسابين مختلفين.

## المرحلة 2 — مخطط الرحلة
- نموذج تفضيلات وميزانية ومدة.
- توليد مسودة برنامج يومي عبر خادم آمن.
- إظهار مصدر كل معلومة ووقت تحديث الأسعار.
- عدم عرض بيانات تقديرية على أنها أسعار مباشرة.

## المرحلة 3 — مصادر السفر
- دراسة مزودي بيانات الطيران والسكن والأنشطة وشروط الاستخدام.
- ربط مصادر متاحة ومرخصة فقط.
- إضافة حالات عدم توفر البيانات وروابط المصدر.

## المرحلة 4 — الاختبار والإطلاق التجريبي
- اختبارات وظيفية وأمنية.
- تجربة مغلقة مع 10 مستخدمين.
- مراقبة الأخطاء والأداء ثم التحسين.
