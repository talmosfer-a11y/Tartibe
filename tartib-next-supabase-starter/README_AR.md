# ترتّب — الحزمة التأسيسية

هذه حزمة بداية لإعادة بناء «ترتّب» باستخدام Next.js وSupabase. ليست تطبيقًا مكتملًا ولا جاهزة للإطلاق.

## ما الموجود؟
- واجهة عربية RTL أولية: الرئيسية، تسجيل الدخول (واجهة فقط)، رحلاتي، وإنشاء رحلة (واجهة فقط).
- إعدادات Supabase للمتصفح والخادم وتحديث الجلسة.
- ملف SQL تأسيسي للجداول وسياسات RLS الأولية.
- مسار OAuth callback كبداية لتدفق تسجيل الدخول.

## ما الذي لم يكتمل؟
- لم يتم اختبار البناء أو الاتصال بقاعدة بياناتك من هذه الحزمة.
- تسجيل الدخول والنماذج لا تعمل بعد؛ يلزم استكمالها واختبارها.
- لا يوجد ربط فعلي بالطيران أو الفنادق أو الأنشطة أو الطقس.
- لم تتم إضافة Gemini بعد. لا تضع أي مفتاح سري في المتصفح.
- سياسات RLS أولية وتحتاج مراجعة واختبار أمني قبل الإطلاق.

## التشغيل محليًا
1. ثبّت Node.js 20 أو أحدث على جهاز تطوير مناسب.
2. انسخ `.env.example` إلى `.env.local`.
3. ضع رابط Supabase ومفتاح anon/publishable في المتغيرات العامة.
4. نفّذ `npm install` ثم `npm run dev`.
5. افتح `http://localhost:3000`.

## متغيرات البيئة
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `GEMINI_API_KEY` (للاستخدام الخادمي مستقبلًا فقط)

## قاعدة البيانات
راجع `supabase/migrations/001_initial_schema.sql` ثم نفّذه في SQL Editor بمشروع Supabase. لا تستخدم مفتاح `service_role` في الواجهة أو GitHub.

## النشر
ارفع المشروع إلى GitHub، ثم اربط المستودع بـ Vercel. أضف متغيرات البيئة في إعدادات Vercel قبل النشر. لا ترفع `.env.local` أو أي مفاتيح سرية إلى GitHub.
